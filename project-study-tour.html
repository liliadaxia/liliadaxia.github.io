PROJECT BRIEF & IMPACT

从研学产品到可转化的品牌方案

国际研学项目并不只是一次旅行产品，而是一个同时面向家长、学生、合作机构和执行团队的复合型教育服务。视觉系统需要承担产品说明、招生转化、合作招商、出团指引和旅程记录等多重功能。通过统一的品牌语言、模块化版式和多场景物料设计，帮助项目从线上传播延展到线下出团体验。

3–18 成长规划

面向 3–18 岁学生与家庭，围绕国际教育成长路径建立研学产品叙事与视觉表达。

4 体验维度

将研学内容梳理为文化浸润、学术赋能、科技探索和自主成长四个维度，让复杂行程更容易被理解和传播。

B2B 招生支持

为合作机构提供招生品宣、物料采购、培训支持与出团服务内容，帮助项目从品牌传播进入实际转化。

BRAND POSITIONING

品牌定位与产品叙事

通过品牌定位梳理，将国际研学从普通旅行产品转化为具有教育价值、成长规划和国际视野的品牌服务。

Brand Mission 走出去，把世界带回来

以真实国际场景建立孩子对世界、学习和自我成长的感知。

Target Audience 3–18 岁国际教育成长家庭

面向重视视野拓展、语言环境和成长规划的亲子家庭。

Destination Focus Singapore Study Tour

以新加坡作为国际教育、城市探索和多元文化体验的核心目的地。

Value Proposition 教育价值、文化浸润、安全保障、成果可视化

让家长能快速理解项目价值，也让合作机构更容易完成转介绍。

PROGRAM SYSTEM

研学产品体系可视化

将新加坡研学行程中的课程、城市探索、文化体验和亲子成长内容，重新组织为清晰的产品结构，方便家长理解，也方便合作机构进行招生介绍。

01文化浸润

城市探索、生活观察、多元文化体验。

02学术赋能

Camp 课程、校园参访、主题学习任务。

03科技探索

前沿产业、创新教育、未来能力启发。

04自主成长

团队协作、独立表达、成果展示与复盘。

RECRUITMENT CAMPAIGN

招生传播视觉系统

将复杂的研学产品信息拆解为适合小红书、朋友圈、社群和合作机构转发的传播素材，帮助项目完成前期种草、咨询引导和报名转化。

01 招生海报

用清晰标题、年龄段、目的地和项目价值降低理解成本。

02 小红书封面 / 朋友圈转发图

将亮点拆成适合移动端浏览的种草内容和转发素材。

03 B端合作推广图

为机构合作、渠道转发和招生说明提供统一视觉框架。

STUDY TOUR MATERIALS

研学出团物料系统

将品牌视觉延展到出团真实场景中，通过装备包、手册、胸牌、贴纸、证书、行李牌和集合识别物料，帮助学生、家长和执行团队在旅程中获得更清晰、安全且统一的品牌体验。

研学手册 装备包 胸牌 行李牌 证书 贴纸 T恤 / 帽子 出团文件袋 旗帜 集合识别物料 书包 手机壳
ITINERARY VISUAL DESIGN

行程安排与信息可视化

通过时间轴和模块化行程设计，将复杂行程转化为可读、可转发、可执行的信息结构。

Before Departure 报名确认 / 证件提醒 / 物料准备

帮助家长提前理解出团流程、准备节点和沟通材料。

During the Journey Camp 课程 / 城市探索 / 家长参观 / 晚宴活动

将每日体验拆解为清晰模块，方便执行团队和家长同步。

After the Tour 照片视频沉淀 / 成果反馈 / 后续转化

让旅程内容继续形成品牌资产和二次传播素材。

JOURNEY DOCUMENTATION

旅程摄影与现场记录

通过现场摄影记录行前集合、课程体验、城市探索和亲子互动，让研学项目不只停留在宣传物料中，而是形成可回顾、可传播、可沉淀的真实品牌内容。

集合出发

优先使用背影、远景和集合识别物料，避免清晰正脸与隐私信息。

课程体验

记录课堂、任务卡和成果展示，让教育价值更容易被家长感知。

城市探索

沉淀城市观察、文化体验和团队协作中的真实内容素材。

PROJECT VALUE

从视觉传播到真实旅程体验

这个项目的价值不只体现在宣传物料设计，而在于将国际研学产品转化为一套可招生、可合作、可执行、可沉淀的品牌体验系统。视觉在其中承担了信息梳理、品牌识别、家长信任建立、合作机构转发和旅程体验统一的作用。
