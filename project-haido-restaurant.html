LES POISSONS / RESTAURANT BRAND VISUAL SYSTEM

Les Poissons海朵餐饮品牌活动视觉系统

海朵餐饮品牌活动视觉系统围绕菜品推广、节气内容、主题活动、品牌荣誉与现场落地等多场景传播展开，通过统一的品牌识别、精致菜品影像、节令内容表达与活动场景化延展，建立兼具品质感、食欲感与营销转化力的品牌视觉系统。

Campaign Posters Seasonal Content Event Visual Onsite Implementation
PROJECT BRIEF & IMPACT

项目背景与商业价值

Les Poissons 海朵的活动视觉需要同时服务菜品推广、节令内容、品牌活动与现场落地。项目重点不是孤立完成海报，而是将不同传播场景收束为可持续延展的餐饮品牌视觉系统。

4 传播模块

菜品推广、节日活动、品牌活动与门店物料统一表达。

42 视觉资产

页面中整理的海报、节气内容、活动板与现场物料可持续复用。

8 现场触点

邀请函、菜单、展架、餐桌布置与合影记录构成落地闭环。

项目价值集中在菜品推广、节日活动、门店物料与线上线下传播的一致表达中。

01 Campaign Posters

菜品与营销海报

围绕菜品推荐、早茶活动、品牌荣誉与节日营销等传播场景，建立统一的餐饮活动海报系统，强化品牌品质感、食欲感与转化记忆点。

02 Seasonal Content System

节气内容视觉系统

以节气为内容线索，结合时令食材、品牌色彩与餐饮场景，形成可持续更新的节令内容视觉资产。

03 Event Visual System

品牌活动视觉

围绕艺术展览、品牌品鉴与主题活动，延展主视觉、邀请函、空间物料与现场传播画面，构建完整的活动视觉系统。

04 Onsite Implementation

现场落地与物料应用

通过门店现场、活动布置、餐桌物料、邀请函与合影记录，呈现视觉设计从线上传播到线下体验的完整落地过程。

PROJECT VALUE

这个项目的重点不是单一画面的完成，而是让菜品推广、节令内容、活动视觉与现场物料形成可连续使用的视觉系统。通过一致的品牌表达，海朵在日常传播和线下体验中更稳定地建立品质感、食欲感与记忆点。
