SIMONKIDS 托育品牌视觉系统

0-3岁托育品牌的 VI、IP 延展、空间物料与活动传播设计。

BACKGROUND
项目背景

托育品牌面对的是家长和孩子两个层面的感知需求：一方面需要让家长感到专业、可靠和有品质；另一方面也需要让孩子感到亲切、柔软和有安全感。因此，视觉系统需要在高级感与亲和力之间保持平衡。

DESIGN GOAL
设计目标

建立统一的品牌识别系统；延展可用于活动、空间和物料的视觉语言；让 IP、色彩和图形元素能够自然融入品牌触点；提升品牌在家长沟通和线下场景中的记忆度。

VISUAL STRATEGY
视觉策略

以柔和色彩、亲和图形和统一版式建立品牌气质。通过 IP 形象、辅助图形和场景化物料，将品牌从单一标识延展为可被反复感知的视觉系统。

APPLICATIONS
应用场景

品牌 VI、IP 延展、空间墙面、活动海报、邀请函、电视背景、包装与日常商业物料。

CAMPAIGN EXTENSION

儿童音乐戏剧活动视觉

活动主视觉、邀请函、电视背景与传播物料设计。在托育品牌视觉系统下，活动视觉承担阶段性传播任务。这个项目延续品牌的亲和气质，通过主视觉、邀请函和电视背景形成统一的活动识别。

GALLERY

视觉展示

PROJECT VALUE

这个项目的重点不是单一画面的完成，而是将品牌视觉放入真实使用场景中，让识别、传播和体验形成更连贯的系统。通过统一的视觉语言，品牌能够在活动、空间和物料中被更稳定地感知和记住。
